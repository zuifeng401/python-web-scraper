### sig 签名拆解

`d.sig`由`Object(s.e)(f)`生成，对应 sig 函数：

```

```

逻辑很简单：把处理完的 payload 拼接上`_p`盐值，做 MD5 再转大写，本地直接复现即可。

这块刚学的时候踩了不少坑，这个拦截器是统一封装的，不是发完请求立刻就解密，中间会经过多层处理，如果不看懂整体 JS 流程，盲目跟栈会跟得头大。
